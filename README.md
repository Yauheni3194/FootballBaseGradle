Приложение для организации матчей по футболу Приложение работает на "Java 21", "Gradle" и "PostgreSQL 17". С приложением можно взаимодействовать через любой браузер.



Как запустить:



На компьютере должен быть установлен и запущен "Docker Desktop".



Запуск проекта:



Откройте терминал/консоль в папке проекта и выполните команду: "docker compose up --build -d"



Примечания к работе:



Для работы в браузере приложение будет доступно по адресу: "http://localhost:8080"



Остановить проект: "docker compose down -v"
